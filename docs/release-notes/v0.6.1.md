# WW-Online 0.6.1

Your room remembers its rules, and reporting a bug takes one button.

0.6.1 plays with 0.6.0 (same network protocol) and needs no re-patch.

## New

- **Hosting remembers your rules.** Change the rules while you host (Full sync, Co-op or your own mix) and the next room you host starts with them, instead of every rule on. Only the rules are kept: the room's items, story and bags still come back from everyone's saves.
- **Settings → Bug report.** **Save bug report** puts your recent logs (the room's server log too if you host, and Dolphin's log if it has one) and a short summary of your version and settings into one zip, and shows it to you. Your Windows user folder is replaced by `%USERPROFILE%`, so your name isn't in it, and nothing is uploaded. **Report an issue** opens the issues page to attach it to.

## Dedicated server

```
docker run -d --name ww-online --restart unless-stopped -p 6969:6969 ghcr.io/datstarkey/ww-online-server:0.6.1
```

See the [self-hosting guide](https://github.com/datstarkey/ww-online/wiki/Self-Hosting). A dedicated server keeps starting from its own settings (`WWO_SHARED_*`).
