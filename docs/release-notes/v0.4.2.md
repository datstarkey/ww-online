# WW-Online 0.4.2

A fix for starting the game.

**No re-patch needed** (only the app changed since 0.4.1), and 0.4.2 plays with 0.4.0 and 0.4.1 (same network protocol).

## Fixed

- **"The game running in Dolphin isn't your patched WW-Online game"** for a game that is patched. WW-Online checks the game by something it only sees once Link is on screen, so a player who took more than a few seconds on the title screen or file select was turned away. It now waits until you load your save ("Your game is running: load your save and WW-Online links up"), however long that takes.

## Dedicated server

```
docker run -d --name ww-online --restart unless-stopped -p 6969:6969 ghcr.io/datstarkey/ww-online-server:0.4.2
```

See the [self-hosting guide](https://github.com/datstarkey/ww-online/blob/main/docs/self-hosting.md). The `WW-Online-Server-0.4.2-*.zip` files below run the server without Docker.
