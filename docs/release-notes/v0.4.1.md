# WW-Online 0.4.1

A fix for jumping while another player appears.

**Patch the game again** after updating: the app asks you to (**Patch now**). 0.4.1 plays with 0.4.0 (same network protocol), but everyone should update.

## Fixed

- **Ground warp when another player appears.** If you were in the air (jumping, falling, gliding) at the moment another player's Link appeared in your game (they loaded into your area or respawned), you were snapped down to the ground below you. It no longer happens.

## Known limitations

- Everything from 0.4.0's list still applies.

## Dedicated server

```
docker run -d --name ww-online --restart unless-stopped -p 6969:6969 ghcr.io/datstarkey/ww-online-server:0.4.1
```

See the [self-hosting guide](https://github.com/datstarkey/ww-online/blob/main/docs/self-hosting.md). The `WW-Online-Server-0.4.1-*.zip` files below run the server without Docker.
