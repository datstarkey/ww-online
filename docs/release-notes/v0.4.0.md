# WW-Online 0.4.0

The sailing freeze is fixed, and the sea chart, treasure charts and Beedle's point card are shared.

**Everyone in a room needs 0.4.0** (the network protocol changed), and everyone needs to **patch the game again**: the app asks you to after it updates (**Patch now**).

## Fixed

- **The boat stopping dead.** While sailing, your boat could suddenly stop, the sail vanish and every item but the Wind Waker stop working until you conducted with it. It happened whenever another player's Link appeared in your game (crossing sea squares, loading an area), which wiped your "riding the boat" state. It no longer does.

## New

**Sea chart and treasure charts** (part of **Shared items**). They only ever grow:
- the treasure and Triforce charts anyone owns;
- charts anyone has had deciphered;
- sunken treasure anyone has salvaged;
- the squares anyone has filled in on the sea chart.

**Beedle's point card** (part of **Shared story**). The room keeps the highest point card and everyone's card is raised to it; points are never taken away. Two players buying in the very same moment can lose a point between them.

## Known limitations

- Salvaged treasure is shared, so once one player salvages a chart's treasure it's gone for everyone, like an opened chest.
- Everything from 0.3.0's list still applies.

## Dedicated server

```
docker run -d --name ww-online --restart unless-stopped -p 6969:6969 ghcr.io/datstarkey/ww-online-server:0.4.0
```

See the [self-hosting guide](https://github.com/datstarkey/ww-online/blob/main/docs/self-hosting.md). The `WW-Online-Server-0.4.0-*.zip` files below run the server without Docker.
